# NEXO — Convenciones para Aider

Plataforma de gestión escolar colombiana.
Stack: PHP multi-tenant (PostgreSQL + Redis) · React/Vite/PWA · C++ edge (Raspberry Pi).

## Reglas absolutas
1. Modifica ÚNICAMENTE los bloques indicados. Nada más.
2. Sin explicaciones salvo petición explícita.
3. Sin refactorizaciones fuera del alcance del fix.
4. Si el fragmento SEARCH no coincide exactamente con el archivo real, repórtalo antes de actuar.
5. Si un fix requiere tocar un archivo no mencionado en el prompt, pregunta primero.
6. Los SEARCH/REPLACE deben ser mínimos: solo líneas que cambian + contexto mínimo para unicidad.
